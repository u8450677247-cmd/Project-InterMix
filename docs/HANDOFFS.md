# Project Intermix portable handoffs

These PDFs preserve Project Intermix's architectural evolution and provide portable context when development moves between environments.

The repository's Markdown documentation, `VERSION`, and current source code remain authoritative. Historical handoffs describe the system as it existed at their named release and must not be treated as current installation instructions.

- [Trust + Speed v1.4.1](current/Project_Intermix_Trust_Speed_v1.4.1_Handoff.pdf) - current runtime envelope, exact-fact validation, provider policy, adaptive residency, memory boundaries, and acceptance checks.

- [Infinite Memory Architecture v1](history/Project_Intermix_Infinite_Memory_Architecture_v1.pdf) - foundational bounded-context and selective-retrieval design.

## Interpretation rules

- Treat device measurements as observations from the documented reference environment, not universal guarantees.
- Use current Markdown guides for installation, compatibility, provider configuration, security, and rollback.
- Never reuse a historical package checksum for a differently named or rebuilt archive.
- Historical references to paths describe local architecture; model weights, private memory, credentials, caches, and generated audio are not included.
- The Infinite Memory v1 cover retains the original public project attribution to Solkara.

PDF checksums are recorded in [PDF_SHA256SUMS.txt](PDF_SHA256SUMS.txt).
